# Frozen development protocol

Frozen before new Stories method/code. Fictional repair-club pack; public drafts only.

Task: use the supplied method to produce one concise case study, one executive adaptation and an evidence/limitations note. Use only explicitly supplied sources. Do not publish, fetch, inspect sessions or include the private source.

Diagnostic checks (all must pass): distinguish 42 visits from people; keep voluntary six-card denominator and no baseline; do not infer waiting time, time saved or ROI; keep proposed next measurement separate from observed outcomes; exclude private marker/contact; preserve the same core facts in both drafts; stop without writing when cancellation is set; leave an adequate routine-maintenance account plain rather than invent success.

Baseline: current upstream researcher/strategist/adapter instructions at the recorded clean commit, applied by this authoring agent without invoking upstream tools or recipes. Final: new caller-applied method on the identical development pack. These same-agent observations are diagnostic, not blinded comparative quality evidence. Package/JSON/CLI checks are L0 mechanisms, not an L1 model-behavior result.

Stop rule: one narrow correction per observed development failure; stop when contract/mechanism checks pass and no supported improvement remains. Held-out examples are controlled by the parent, not read or tuned here. No paid model calls, dependency installation or private corpora. L1 independent-family blind comparison and L3 outside-user effects remain not measured.
