# Source and reuse

Adapted from the evidence gathering, story strategy and audience-adaptation concepts in `amplifier-module-stories`, inspected at commit `bc4b70c20c787488067c8a3098211a12252a370d`. The source identifies its upstream as [ramparte/amplifier-stories](https://github.com/ramparte/amplifier-stories). A live upstream/fork comparison was not performed for this local extraction; the frozen source commit and selected-file hashes are retained in the repository evaluation records.

The source LICENSE is MIT, copyright (c) 2026 Amplifier Stories Contributors. Its notice is included in this method's LICENSE. New packaging, contracts, diagrams and local checks are original additions to this extraction; no upstream document renderer, asset pack or font is included.

Retained ideas: trace each metric to evidence; choose audience and narrative before drafting; preserve the core account during adaptation; show missing data.

Deliberately omitted machinery: session mining, specialist-agent namespace dependencies, autonomous recipes and release/distribution actions, document conversion adapters, fixed private paths and automatic dependency installation. Example numbers and claims from the original templates are not evidence for a real project.

The input fixture and example output in this local package describe a fictional repair club. They are not a customer case study or a measured product result.
