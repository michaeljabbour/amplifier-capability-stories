# Placement: skill at rung 2, engine LLM

The expertise lives in the caller's context. A person asks for the work and collaborates through review. One caller keeps one evidence spine across two drafts; no specialist system or independent runtime is required.

| Need | Score | Evidence |
| --- | --- | --- |
| N1 Path | 1 | Known steps: select, map, draft, adapt, review |
| N2 Context load | 1 | The bounded pack fits the caller's main window |
| N3 Duration/presence | 1 | Minutes, with the person present |
| N4 Initiative | 0 | Only when asked |

Sum **3 → rung 2**. Situational narrative judgment favors a skill. The read-only structural helper is a tool under the skill, not a sealed writing engine.

| Gate | Assessment | Ceiling consequence |
| --- | --- | --- |
| G1 Verifiability | Fails for overall writing quality: IDs and bounds are cheap to test, usefulness/entailment are not automatically established | 5 |
| G2 Reversibility | Pass for the defined draft-only contract; irreversible distribution is outside it | No lower cap |
| G3 Trifecta broken | Pass for the defined local/offline contract: no outbound channel is included | No lower cap; an outbound host changes this assessment |
| G4 Isolation | Not guaranteed by an instruction file; caller must restrict mounted/selected context | 6 |
| G5 Budget | No model-routing measurement or hard token/time control is shipped | 7 |
| G6 Ownership | Person reviews each account; no unattended service ownership is asserted | No lower cap for this operator-led scope |

Lowest ceiling **5**; need rung 2 is below it. This does not authorize moving private material into an online caller. The host's actual access/dataflow still matters.

H1 is **not** counted: mandatory independent verification is not a runtime part of this smallest version, although release evaluation should be independent. H2 false (no specialists required), H3 true (portable method), H4 false (one coherent job). One check → a single skill. Composition does not raise its autonomy.

Replaceability gaps: **R5** remains unmeasured. The claim ledger compensates for unsupported claims and factual drift during compression; compare it with a length-matched placebo and an ablation before claiming benefit. R1 contract, R2 caller/verifier choice, R3 one job, and R4 no embedded account/memory are supported by the package design, not by outside-user results.

L0: package, read-only checker, pinned shared discovery lifecycle in a temporary destination. L1: frozen fictional trap/leave-alone/stop/consistency cases with baseline and placebo, blind different-family adjudication; **not established by same-agent development samples**. L2 not applicable to this generative method. L3 **not measured**. [Benchmark](BENCHMARK.md) records thresholds and remaining work.

Disposition: **Extract** a bounded method from the larger bundle, preserving attribution and keeping the old bundle separate.
